# 外部目录快照

这里保存从公开 Grok Bot 目录抓取的结构化数据快照，用于把其中的 Bot 按需转写为本仓库的契约模板。

| 文件 | 内容 |
| --- | --- |
| `imported-bots.json` | 110 个 Bot 的完整数据：名称、分组、运行方式、上手难度、耗额度、开始前准备、一键 Prompt 全文、手动步骤、验收、备注、关联 |
| `imported-counts.json` | 公开计数的复制计数快照（2026-11-07） |

抓取方式：公开页面与公开计数接口。快照只保存站外可公开访问的数据。

## 署名与授权

- 原始 Prompt 与文案的著作权归原提交者所有。
- 转写进本仓库时只做**结构化转写**（契约字段）；原始 Prompt 全文按原样留档在对应模板的 `examples/source-prompt.md`，供核对，不附来源链接。
- 本仓库对导入内容不宣称原创，也不用于商业捆绑。
- 如果原作者要求下架某个 Bot，删除对应 `templates/**/md-*` 目录并在 CHANGELOG 记录即可。
