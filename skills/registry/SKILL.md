# 名册与规则维护

成功运行后，把本文件粘贴到 Grok Bot 中：

> 把刚才的流程保存为名为“名册与规则维护”的技能。

一个有用的技能要说明来自 [Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations) 的六个字段：

## 1. 何时使用

组织里的经理或员工加入、退出、换职责，或者规则、边界、等级、可调用工具发生变化时—— 先改文件再传话，绝不让变更只留在对话里。


## 2. 所需输入与访问权限

- 现行名册文件（/workspace/company/registry.md）
- 主人提出的变更（加入、退出、改职责、改边界）
- 当前 Bot 列表与群组成员身份

## 3. 操作顺序

1. 读取名册与现有列表，逐条对比差异。
2. 先修改名册与分派单文件，再草拟对外传话。
3. 变更只写最小差异，不重写整张表。
4. 给每条变更标注日期与来源。
5. 保存后向主人回执：改了哪条、影响了谁。

## 4. 如何验证结果

名册中的每个条目都能指向一个真实存在的 Bot 或本地员工；文件已保存；没有条目只存在于对话中； 对外传话草稿标注「草稿」且未发送。


## 5. 返回什么

更新后的名册与分派单、变更清单（条目、日期、来源）、待发送的传话草稿。


## 6. 什么需要审批

不要发送、发布、支付或联系任何人；不要修改其他 Bot 的描述与记忆；拿不准的变更先问主人。


在输入框中键入 `/` 来引用已保存的技能。如果没有出现，打开 **设置 → 插件 → 你的插件** 并为本 Bot 启用它。
