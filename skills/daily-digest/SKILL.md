# 每日摘要

成功运行后，把本文件粘贴到 Grok Bot 中：

> 把刚才的流程保存为名为“每日摘要”的技能。

一个有用的技能要说明来自 [Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations) 的六个字段：

## 1. 何时使用

主人要一份映射到既定优先事项、带来源链接的「变了什么、该关注什么」摘要， 而不是把所有频道倾倒一遍。


## 2. 所需输入与访问权限

- 优先事项文档或钉住的当前优先清单
- 已批准的频道（Slack、邮件、日历、笔记）
- 时间窗口（默认 Bot 时区的昨日起）

## 3. 操作顺序

1. 重读优先事项文档；缺失就询问后停止。
2. 只扫描窗口内的已批准来源。
3. 丢掉无法映射到任何优先项的内容。
4. 每条保留项写清来源、为什么重要、建议下一步、以及主人是否欠一个决策。

## 4. 如何验证结果

每条都有来源链接或消息指针；主人标记过的噪音不出现；没有发送消息，没有改会议。


## 5. 返回什么

一份短摘要加「需要决策」小节；以及扫描过的来源操作日志。


## 6. 什么需要审批

未经主人明确批准，不要发送消息、不要改动会议时间、也不要创建工单。


在输入框中键入 `/` 来引用已保存的技能。如果没有出现，打开 **设置 → 插件 → 你的插件** 并为本 Bot 启用它。
