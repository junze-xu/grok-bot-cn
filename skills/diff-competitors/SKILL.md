# 竞品差异对比

成功运行后，把本文件粘贴到 Grok Bot 中：

> 把刚才的流程保存为名为“竞品差异对比”的技能。

一个有用的技能要说明来自 [Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations) 的六个字段：

## 1. 何时使用

一小组竞品需要被快照，只浮现实质变化——价格、变更日志、招聘、话术。


## 2. 所需输入与访问权限

- 指定竞品（3–8 个）
- /workspace 中上次快照（如存在）
- 「实质」的定义（价格、打包、定位、指定岗位招聘，除非主人重新定义）

## 3. 操作顺序

1. 加载上次快照；没有就先取基线，写完即停。
2. 抓取当前公开页面；数字照引，不要转述。
3. 做差异；未变化的属性保持安静。
4. 写实质变化备忘，附 URL 和日期。

## 4. 如何验证结果

每个变化都有前后对比和 URL；没有「他们似乎正聚焦于」这类含糊话。


## 5. 返回什么

基线或差异备忘。未变化的竞品合并成一行，让主人知道它们被检查过。


## 6. 什么需要审批

不要抓取主人未授权的登录后页面；不要把备忘发到 Slack 或 X。


在输入框中键入 `/` 来引用已保存的技能。如果没有出现，打开 **设置 → 插件 → 你的插件** 并为本 Bot 启用它。
