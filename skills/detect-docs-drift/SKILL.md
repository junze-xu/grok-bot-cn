# 检测文档漂移

成功运行后，把本文件粘贴到 Grok Bot 中：

> 把刚才的流程保存为名为“检测文档漂移”的技能。

一个有用的技能要说明来自 [Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations) 的六个字段：

## 1. 何时使用

README、API 文档或注释声称的行为可能已与当前代码不符，主人需要一份文档差异草稿—— 不是一次提交。


## 2. 所需输入与访问权限

- GitHub 仓库或附带的文档加代码
- 主人指定的路径（README、API 文档、OpenAPI、生成的引用）
- 可选的上次已知良好标签

## 3. 操作顺序

1. 打开指定文档和它们描述的代码（路由、flag、类型、CLI）。
2. 把每处漂移列成「文档声称 vs 代码事实」，附路径。
3. 起草一份主人可直接粘贴的文档 diff；优先最小且真实的修改。
4. 不要提交、推送或合并；也不要为迁就错的 README 去「修正」代码。

## 4. 如何验证结果

每处漂移都引用一个文档路径和一个代码路径；没有编造 API；交付物是草稿，未发布。


## 5. 返回什么

漂移对照表、拟议的文档补丁草稿，以及已读文件的操作日志。


## 6. 什么需要审批

不要提交、合并或发布文档；不要改 GitHub Wiki 或生产文档站。


在输入框中键入 `/` 来引用已保存的技能。如果没有出现，打开 **设置 → 插件 → 你的插件** 并为本 Bot 启用它。
