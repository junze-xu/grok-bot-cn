# 对账费用

成功运行后，把本文件粘贴到 Grok Bot 中：

> 把刚才的流程保存为名为“对账费用”的技能。

一个有用的技能要说明来自 [Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations) 的六个字段：

## 1. 何时使用

一周的费用要对照收据和政策，产出例外草稿——总额必须能回对到来源。


## 2. 所需输入与访问权限

- 费用系统导出或连接器
- 财务收件箱/附带收据
- 书面报销政策（已签署的，不是记忆）

## 3. 操作顺序

1. 先对来源系统求总额；这个数是分母。
2. 对收据；缺类目和政策例外都要带政策引用标出。
3. 每位负责人起草一条跟进；不发送。
4. 返回汇总、例外、草稿、以及可对账的总额。

## 4. 如何验证结果

汇总总额等于来源系统总额或有解释的差额；每条例外都引用政策章节。


## 5. 返回什么

周汇总、带政策引用的例外表、未发送的跟进草稿、操作日志。


## 6. 什么需要审批

不要发送跟进；不要修改报销记录；也不要批准任何支出。


在输入框中键入 `/` 来引用已保存的技能。如果没有出现，打开 **设置 → 插件 → 你的插件** 并为本 Bot 启用它。
