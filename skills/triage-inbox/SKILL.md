# 收件箱分类

成功运行后，把本文件粘贴到 Grok Bot 中：

> 把刚才的流程保存为名为“收件箱分类”的技能。

一个有用的技能要说明来自 [Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations) 的六个字段：

## 1. 何时使用

收件箱需要一份排好序的工作清单和草稿回复，让主人不必住在 Gmail 里也能归零。


## 2. 所需输入与访问权限

- Gmail（或指定邮箱）连接器
- VIP 名单和忽略名单（如主人保存过）
- 时间窗口（默认上次运行以来）

## 3. 操作顺序

1. 取窗口内的消息；未经要求不要标记已读。
2. 分成需回复、仅供参考、通讯刊物、收据或忽略。
3. 只对需回复起草回复；有示例就用主人语气。
4. 标记任何像账单、法务截止或安全警报的邮件。

## 4. 如何验证结果

没有发出任何邮件；未经明确批准没有归档/删除；安全样邮件绝不自动忽略。


## 5. 返回什么

分桶清单，需回复项附草稿回复；以及「今日处理」Top 5。


## 6. 什么需要审批

未经批准不要发送、删除或退订；刊物退订属 L2+，单列。


在输入框中键入 `/` 来引用已保存的技能。如果没有出现，打开 **设置 → 插件 → 你的插件** 并为本 Bot 启用它。
