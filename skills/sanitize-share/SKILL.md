# 分享脱敏

成功运行后，把本文件粘贴到 Grok Bot 中：

> 把刚才的流程保存为名为“分享脱敏”的技能。

一个有用的技能要说明来自 [Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations) 的六个字段：

## 1. 何时使用

主人想把 Bot 作为公开模板分享，链接发出前需要把描述、技能和例行程序里的 密钥、客户数据和内部 URL 清掉。


## 2. 所需输入与访问权限

- Bot 当前的描述、技能列表和例行程序文本
- 主人准备附加到资料上的额外文件（可选）

## 3. 操作顺序

1. 读描述和任何技能/例行程序文本。
2. 标记 API key、token、邮箱、客户名、内部主机名和预发 URL。
3. 提出脱敏后的描述；不要静默删除常驻安全规则。
4. 确认 share-safe：身份、job、边界、首任务还在；密钥清除。

## 4. 如何验证结果

无密钥状字符串、无 @客户域名、无 .internal 主机；脱敏后审批边界仍在。


## 5. 返回什么

可安全分享的 PROFILE 和移除内容的 diff，附提醒：链接是公开的，且不复制电脑或登录状态。


## 6. 什么需要审批

不要自己创建公开分享链接；主人接受脱敏后，由他从 Bot 里复制。


在输入框中键入 `/` 来引用已保存的技能。如果没有出现，打开 **设置 → 插件 → 你的插件** 并为本 Bot 启用它。
