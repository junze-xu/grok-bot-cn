# 客户健康排名

成功运行后，把本文件粘贴到 Grok Bot 中：

> 把刚才的流程保存为名为“客户健康排名”的技能。

一个有用的技能要说明来自 [Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations) 的六个字段：

## 1. 何时使用

一个客户组合需要从用量、支持、续约时间点和干系人活跃度得出排名观察清单—— 要证据，不要感觉。


## 2. 所需输入与访问权限

- 客户名单或 CRM 客群
- 风险阈值（缺失就问一次：用量下滑、P1 未结、距续约天数）
- 主人批准作为来源的支持、账单和成功团队记录

## 3. 操作顺序

1. 加载当前数据；某来源不可用就点名，用现有材料继续——绝不悄悄用上周文件替代。
2. 按保存的阈值给每个账户打分。
3. 写证据、为什么重要、建议下一步。
4. 排名；扩张信号与流失信号分开。

## 4. 如何验证结果

每个排名都有阈值引用；没有给客户发邮件；CRM 未编辑。


## 5. 返回什么

带证据链接的排名观察清单、建议下一步、「需要人工」标记。


## 6. 什么需要审批

不要联系客户；不要改 CRM；不要退款或发放额度。


在输入框中键入 `/` 来引用已保存的技能。如果没有出现，打开 **设置 → 插件 → 你的插件** 并为本 Bot 启用它。
