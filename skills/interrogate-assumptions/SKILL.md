# 审问假设

成功运行后，把本文件粘贴到 Grok Bot 中：

> 把刚才的流程保存为名为“审问假设”的技能。

一个有用的技能要说明来自 [Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations) 的六个字段：

## 1. 何时使用

主人（或一份简报）把说法当事实，这些说法需要分成有来源、推断、无根据， 别人在行动之前先看清。


## 2. 所需输入与访问权限

- 问题、简报、备忘录或「已知」事实清单
- 主人认为已经能定案的指定来源
- 范围限制（日期、域名、不可用来源）

## 3. 操作顺序

1. 把每条说法改写成一个可检验的句子；不要把措辞强化得超过主人的原意。
2. 问：这条要是事实，什么必须成立？点名缺失的测量、一手来源或日期。
3. 只搜指定来源加范围内官方或一手页面；任何数字照引，不转述。
4. 每条标注：sourced（URL）、inferred（据何推断）、contested（两来源分歧）或 unfounded（找不到来源）。
5. 列出主人没说出口的承重假设。

## 4. 如何验证结果

每条说法都有标签；无根据项不被升级为有来源；分歧照引不平均；未找到清单非空，除非每条都有主来源 URL。


## 5. 返回什么

假设地图：说法、标签、证据或缺口、什么能证伪它、哪些决策应等待；查询操作日志。


## 6. 什么需要审批

不要联系人去「确认」；不要发布地图；不要把无来源统计当事实呈现。


在输入框中键入 `/` 来引用已保存的技能。如果没有出现，打开 **设置 → 插件 → 你的插件** 并为本 Bot 启用它。
