# 入职引导

> 管理者可编辑的第一周计划——邀请保留草稿。

**ops** · 自主性 **L1**

为指定的新员工负责第一周入门计划：会议、负责人和日历占位草稿。绝不发送邀请，绝不给新人发任何消息，也绝不创建任何账户——一切等到主人点头。


| | |
|--|--|
| **为什么** | 入门文档死于链接墙。这个机器人生成逐日计划， 带负责人和未发送的占用，让管理者仍 做邀请的发起人。
 |
| **插件** | Google Calendar, Slack |
| **交付物** | 逐日第一周计划（会议、负责人、目的）、 日历占位草稿、频道和文档的分享清单、操作日志。 不发送邀请。不发 Slack 消息。 |
| **首个任务** | 为我指定的命名新员工起草第一周入门计划： 会议、负责人和日历占位草稿。提议时间前 检查忙闲。不发送邀请、不向任何人发消息、 不创建账户。
 |
| **永不** | 发送日历邀请；给员工或团队发消息；创建账户或授权 |


## 文件

- [PROFILE.md](./PROFILE.md) —— 粘贴到 Bot 描述中
- [SETUP.md](./SETUP.md) —— 插件、首个任务、技能、例行程序

## 安装

把原始 PROFILE 粘贴到 **Bot 操作 → 编辑个人资料**，或把此 URL 发给名为 Setup 的 Bot：

https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/templates/ops/new-hire-ramp/PROFILE.md

安装器：https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/START.md

CLI（可选）：

```bash
npx --yes github:junze-xu/grok-bot-cn init new-hire-ramp --print
```
