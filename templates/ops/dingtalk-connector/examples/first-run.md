# 示例首跑 — 钉钉

原设定的验收话术（导入模板的示例，用你环境里的真实产物替换）
原设定步骤：
1. 打开钉钉开发者后台，新建一个企业内部应用，拿到 Client ID 和 Client Secret
2. 应用权限先只开"读"（通讯录、待办、日程的读取），要发消息、写待办的时候再加
3. 发上面的 Prompt，按提示接管填 Key

原设定提醒：
建应用要企业组织的管理员权限。发出去的是给同事的消息，按错了收不回来，所以写权限最后再开。来源：https://github.com/open-dingtalk/dingtalk-mcp

> 验收话术：发「我还有哪些待办没做」→ 收到清单，和钉钉里的对得上。

跑通后把这段替换为你环境里第一次真实运行的产物。
