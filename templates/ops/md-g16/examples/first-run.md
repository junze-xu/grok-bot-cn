# 示例首跑 — 企业微信

来源站点的验收话术（导入模板的示例，用你环境里的真实产物替换）
原设定步骤：
1. 在企业微信后台建一个智能机器人，拿到 Bot ID 和 Secret
2. 能选权限的话，先只开读取类的，要写的时候再加
3. 发上面的 Prompt，按提示接管填 Key

原设定提醒：
这张卡能做的写操作最多（消息、邮件、文档、日程），按错了发出去的是给同事和客户的东西。不确定就一直停在只读。来源：https://github.com/WeComTeam/wecom-cli

> 验收话术：发「我今天有什么日程」→ 收到日程，和企业微信里的对得上。

跑通后把这段替换为你环境里第一次真实运行的产物。
