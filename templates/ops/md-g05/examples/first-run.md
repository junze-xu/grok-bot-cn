# 示例首跑 — 飞书

来源站点的验收话术（导入模板的示例，用你环境里的真实产物替换）
原设定步骤：
1. 先在浏览器里建一个飞书自建应用（按 lark-cli 的说明）
2. 点授权链接，权限先只勾"读"（日历、文档、妙记），发消息、审批这类写权限要用的时候再加

原设定提醒：
lark-cli 能管日历、文档、表格、消息、邮件、审批，能力很全，所以权限更要收紧。来源：Day 0、Kin https://x.com/KinGao476942/status/2110325058585698654 ；官方仓库 https://github.com/larksuite/cli 。G04、F02、C23 这些 Bot 都依赖它。

> 验收话术：发「我明天有哪些日程」→ 收到日程，和飞书里的对得上。开了写权限后，再试「在飞书新建一个文档，标题叫'Bot 测试'」→ 飞书里出现这个文档。

跑通后把这段替换为你环境里第一次真实运行的产物。
