# 发布排期

> 盯着"已录待发布"的积压，按平台排好本周的发布表。

**creator** · 自主性 **L1** · 运行方式：定时（每周一 9:00）

。请把下面的内容记成长期设定，并建好定时任务：盯着"已录待发布"的积压，按平台排好本周的发布表。每次收到任务：读进度表，找出「已剪」和「已录」的内容；按我的发布习惯排本周的发布表：日期｜平台｜内容｜需要的素材（封面、文案）还缺什么；积压超过 2 周的，标「⚠️ 积压」。

| | |
|--|--|
| **为什么** | 盯着"已录待发布"的积压，按平台排好本周的发布表。把这一步做成可重复、可审查的产出，代替每次手搓。 |
| **插件** | 无需插件 |
| **交付物** | 一份可交付给主人的成果与一句回执，事实与推断分开。产出存放在 /workspace/md-c06/。 |
| **首个任务** | 发一句「盯着"已录待发布"的积压，按平台排好本周的发布表。」，用第一个真实任务跑通流程，把结果发回本对话。 |
| **永不** | 只排期、只提醒，不替我发布；发送、发布或回复任何人；支付、购买或提交订单 |

上手难度：难度 ★；耗额度：低。
