# 知识库投喂

> 用 iOS 快捷指令 + Webhook，在手机上一键把任何内容丢进你的知识库。

**creator** · 自主性 **L1** · 运行方式：技能 · 来源：mdldm.club/C10

：用 iOS 快捷指令 + Webhook，在手机上一键把任何内容丢进你的知识库。（完成后把这一步的真实产物交给对应负责人。）

| | |
|--|--|
| **为什么** | 用 iOS 快捷指令 + Webhook，在手机上一键把任何内容丢进你的知识库。把这一步做成可重复、可审查的产出，代替每次手搓。 |
| **插件** | 无需插件 |
| **交付物** | 一份可交付给主人的成果与一句回执，事实与推断分开。产出存放在 /workspace/md-c10/。 |
| **首个任务** | 发一句「用 iOS 快捷指令 + Webhook，在手机上一键把任何内容丢进你的知识库。」，用第一个真实任务跑通流程，把结果发回本对话。 |
| **永不** | 不回复每一条投喂，只在每天整理时汇总；发送、发布或回复任何人；支付、购买或提交订单 |

上手难度：难度 ★★★；耗额度：低。

## 文件

- [PROFILE.md](./PROFILE.md) —— 粘贴到 Bot 描述中
- [SETUP.md](./SETUP.md) —— 插件、首个任务、技能、例行程序

## 安装

把原始 PROFILE 粘贴到 **Bot 操作 → 编辑个人资料**，或把此 URL 发给名为 Setup 的 Bot：

https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/templates/creator/md-c10/PROFILE.md

安装器：https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/START.md

CLI（可选）：

```bash
npx --yes github:junze-xu/grok-bot-cn init md-c10 --print
```
