# 示例首跑 — 知识库投喂

来源站点的验收话术（导入模板的示例，用你环境里的真实产物替换）
原设定步骤：
1. 在 Bot 设置里拿到 Webhook 地址
2. 在快捷指令里新建一个"分享表单"类型的指令：获取分享的内容 → 用「获取 URL 内容」以 POST 方式发到 Webhook 地址
3. 以后在任意 App 里点分享 → 选这个快捷指令

原设定提醒：
Webhook 地址相当于钥匙，别公开。来源：Day 0（铁柱方法）。快捷指令的具体参数以 Day 0 教程为准。

> 验收话术：在手机上分享一个网页给快捷指令 → 当晚收到整理汇总。
