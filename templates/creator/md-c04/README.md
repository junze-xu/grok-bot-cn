# 评论 FAQ

> 每周汇总各平台评论区的高频问题，出一份 FAQ，再给几条下期选题建议。

**creator** · 自主性 **L1** · 运行方式：定时（每周一 10:00） · 来源：mdldm.club/C04

。请把下面的内容记成长期设定，并建好定时任务：每周汇总各平台评论区的高频问题，出一份 FAQ，再给几条下期选题建议。每次收到任务：读取各平台过去 7 天的新评论和私信里的提问；把意思相同的问题合并，按出现次数排序；出两样东西：。

| | |
|--|--|
| **为什么** | 每周汇总各平台评论区的高频问题，出一份 FAQ，再给几条下期选题建议。把这一步做成可重复、可审查的产出，代替每次手搓。 |
| **插件** | 无需插件 |
| **交付物** | 一份可交付给主人的成果与一句回执，事实与推断分开。产出存放在 /workspace/md-c04/。 |
| **首个任务** | 发一句「每周汇总各平台评论区的高频问题，出一份 FAQ，再给几条下期选题建议。」，用第一个真实任务跑通流程，把结果发回本对话。 |
| **永不** | 不替我回复任何评论；发送、发布或回复任何人；支付、购买或提交订单 |

上手难度：难度 ★★；耗额度：中。
