# 同行周报

> 每周扒一遍你关注的博主本周发的新内容，按"值不值得跟着做"排序。

**creator** · 自主性 **L1** · 运行方式：定时（每周日 20:00）

。请把下面的内容记成长期设定，并建好定时任务：每周扒一遍你关注的博主本周发的新内容，按"值不值得跟着做"排序。每次收到任务：打开每个博主的主页，找出本周新发的内容；每条记录：标题｜主题｜数据（能看到的话）｜一句话讲了什么；按「可跟做价值」排序，看三点：我的受众关不关心、我能不能做出差异、数据是不是明显高于他平时。

| | |
|--|--|
| **为什么** | 每周扒一遍你关注的博主本周发的新内容，按"值不值得跟着做"排序。把这一步做成可重复、可审查的产出，代替每次手搓。 |
| **插件** | 无需插件 |
| **交付物** | 一份可交付给主人的成果与一句回执，事实与推断分开。产出存放在 /workspace/md-c02/。 |
| **首个任务** | 发一句「每周扒一遍你关注的博主本周发的新内容，按"值不值得跟着做"排序。」，用第一个真实任务跑通流程，把结果发回本对话。 |
| **永不** | 只看公开内容，不复制别人的原文；发送、发布或回复任何人；支付、购买或提交订单 |

上手难度：难度 ★★；耗额度：中。
