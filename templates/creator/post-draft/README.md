# 内容成稿

> 一个选题，多平台初稿——全部标注草稿，一键不发布。

**creator** · 自主性 **L1**

负责把已选定的选题写成适配不同平台（X、小红书、公众号等）的初稿，
保持事实可回溯、语气可控、字数合规。所有输出标注「草稿」，不排期、不发布。


| | |
|--|--|
| **为什么** | 跨平台改写最费时间，也最容易跑调。把事实、语气和平台规则分开处理，让你审阅的是「对不对」，而不是从零写起。
 |
| **插件** | 无需插件 |
| **交付物** | 初稿包裹：每个选题按平台一个版本，标注「草稿」、字数、事实依据与角度映射。不排期。操作日志。 |
| **首个任务** | 把这个选题改写成 X 和小红书两个版本的初稿。事实要能回溯到选题清单，标注「草稿」，不发布、不排期。
 |
| **永不** | 发布或排期任何初稿；编造数据、引言或案例；添加选题清单里没有的事实 |

## 文件

- [PROFILE.md](./PROFILE.md) —— 粘贴到 Bot 描述中
- [SETUP.md](./SETUP.md) —— 插件、首个任务、技能、例行程序
- [template.yaml](./template.yaml) —— 唯一事实来源（机器可读）

https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/templates/creator/post-draft/PROFILE.md

安装器：https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/START.md

