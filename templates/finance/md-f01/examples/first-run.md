# 示例首跑 — 报销发票

来源站点的验收话术（导入模板的示例，用你环境里的真实产物替换）
原设定步骤：
1. **登录京东**：让 Bot 打开 jd.com 的登录页 → 点"接管" → 自己扫码或输验证码登录 → 交还控制权。之后登录状态会留在这个 Bot 的浏览器里
2. **认领专属邮箱**：让 Bot 认领一个 @mail.grokbot.com 邮箱，把地址填进 Prompt 的「收票邮箱」
3. **填好 Prompt 里的 {{ }}**：抬头、税号、地址关键词都要换成你自己的，再发出去

原设定提醒：
- **只在你自己的京东账号上操作**。公司抬头和税号属于公司信息，用之前确认公司允许这样报销
- 京东的换开入口和规则可能会变，单张申请失败很正常，以汇总表为准
- 登录状态过期了，就重新"接管"登录一次
- 玩法来源：铁柱 https://x.com/cgnot996/status/2115345115137053105

> 验收话术：发：**"换一下上个月寄到驻场地址的发票"**
→ 先收到一张待确认的订单表。确认后，它逐个申请换开，最后收到一个发票压缩包和一张汇总表，就算成功

跑通后把这段替换为你环境里第一次真实运行的产物。
