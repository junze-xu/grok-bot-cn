# 纪念日提醒

> 生日、纪念日前 7 天提醒你，还附上礼物建议。

**personal** · 自主性 **L1** · 运行方式：定时（每天 9:00）

。请把下面的内容记成长期设定，并建好定时任务：生日、纪念日前 7 天提醒你，还附上礼物建议。每次收到任务：7 天后有纪念日的：推送提醒 + 3 个礼物建议（符合喜好和预算，写清楚为什么选它）；当天：再提醒一次，附一段可以参考的祝福语（你自己改一改再发）；其他时候不发。

| | |
|--|--|
| **为什么** | 生日、纪念日前 7 天提醒你，还附上礼物建议。。把这一步做成可重复、可审查的产出，代替每次手搓。 |
| **插件** | 无需插件 |
| **交付物** | 一份可交付给主人的成果与一句回执，事实与推断分开。产出存放在 /workspace/md-l11/。 |
| **首个任务** | 发一句「生日、纪念日前 7 天提醒你，还附上礼物建议。」，用第一个真实任务跑通流程，把结果发回本对话。 |
| **永不** | 礼物只推荐，不下单；发送、发布或回复任何人；支付、购买或提交订单 |

上手难度：难度 ★；耗额度：低。
