# 自学课程

> 把任何资料变成一门自学课，再按间隔复习的节奏提醒你复习。

**personal** · 自主性 **L1** · 运行方式：定时（复习日） · 来源：mdldm.club/L18

。请把下面的内容记成长期设定，并建好定时任务：把任何资料变成一门自学课，再按间隔复习的节奏提醒你复习。（完成后把这一步的真实产物交给对应负责人。）

| | |
|--|--|
| **为什么** | 把任何资料变成一门自学课，再按间隔复习的节奏提醒你复习。把这一步做成可重复、可审查的产出，代替每次手搓。 |
| **插件** | GitHub |
| **交付物** | 一份可交付给主人的成果与一句回执，事实与推断分开。产出存放在 /workspace/md-l18/。 |
| **首个任务** | 发一句「把任何资料变成一门自学课，再按间隔复习的节奏提醒你复习。」，用第一个真实任务跑通流程，把结果发回本对话。 |
| **永不** | 内容只从我给的资料里来，不另外编；我连续 3 天没学，就问我要不要调整进度，不要一直催；发送、发布或回复任何人 |

上手难度：难度 ★★；耗额度：中。

## 文件

- [PROFILE.md](./PROFILE.md) —— 粘贴到 Bot 描述中
- [SETUP.md](./SETUP.md) —— 插件、首个任务、技能、例行程序

## 安装

把原始 PROFILE 粘贴到 **Bot 操作 → 编辑个人资料**，或把此 URL 发给名为 Setup 的 Bot：

https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/templates/personal/md-l18/PROFILE.md

安装器：https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/START.md

CLI（可选）：

```bash
npx --yes github:junze-xu/grok-bot-cn init md-l18 --print
```
