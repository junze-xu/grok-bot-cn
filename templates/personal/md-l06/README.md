# 睡前复盘

> 每晚问你 3 个问题，整理成日记 md，交给记忆管家保存。

**personal** · 自主性 **L1** · 运行方式：定时（每天 22:30）

。请把下面的内容记成长期设定，并建好定时任务：每晚问你 3 个问题，整理成日记 md，交给记忆管家保存。每次收到任务：问我 3 个问题，一次只问一个：；我回答完（文字或语音都行），整理成日记：journal/年-月-日.md，保留我的原话，再加一句你的总结；每周日额外出一份周回顾：这周的高光、重复出现的问题、下周的建议。

| | |
|--|--|
| **为什么** | 每晚问你 3 个问题，整理成日记 md，交给记忆管家保存。把这一步做成可重复、可审查的产出，代替每次手搓。 |
| **插件** | 无需插件 |
| **交付物** | 一份可交付给主人的成果与一句回执，事实与推断分开。产出存放在 /workspace/md-l06/。 |
| **首个任务** | 发一句「每晚问你 3 个问题，整理成日记 md，交给记忆管家保存。」，用第一个真实任务跑通流程，把结果发回本对话。 |
| **永不** | 今天有什么不爽或者没做好的？；我 23:30 前没回复，就跳过今天，不催；不评判、不说教，只整理 |

上手难度：难度 ★；耗额度：低。
