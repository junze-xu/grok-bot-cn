# 示例首跑 — 杂活哥

原设定的验收话术（导入模板的示例，用你环境里的真实产物替换）
原设定步骤：
1. **注册 OpenRouter 拿 Key**：设好额度上限，Key 先存在你的密码管理器里
2. **发 Prompt 并接管填 Key**：Bot 提示「请接管填 Key」时，点「接管」，在它打开的文件里粘贴 Key、保存，再交还控制权
3. **确认定时任务**：每日巡检按通用 B 确认
4. **让别的 Bot 也能派活**：告诉总管 Bot（M01）「零碎杂活都转给杂活哥」。比如：「给杂活哥安排活：先问内容雷达今天有什么 AI 新闻，再按我的风格写一篇长文初稿，写完发我」。想更省，可以配合 M05 额度管家一起用

原设定提醒：
- **Key 不要发进聊天**。一律用「接管」自己填，Bot 回复里也不能出现 Key；录屏、截图记得打码
- 免费通道可能记日志，密钥、隐私数据、没公开的业务别交给它
- 免费模型质量不稳定，重要的活自己过一眼
- 云电脑整个账号共享，Key 文件放一次，其他 Bot 也能用
- 来源：麦当 Day 1《Grok Bot 省钱秘籍》模板 B + 模板 C

> 验收话术：发：**「把这段话翻成英文，再起 3 个标题：{{随便一段话}}」**
→ 收到翻译和标题，结尾标着「本次用：xxx（免费）」，就算搭好了。第二天早上收到三行巡检，说明定时也生效了

跑通后把这段替换为你环境里第一次真实运行的产物。
