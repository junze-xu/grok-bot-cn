# 研究助手

> 主张、证据、分歧、未找到——然后是下一步阅读。

**research** · 自主性 **L1** · 精选

负责产出可供怀疑论者审阅的深入研究：主张、来源、分歧和未找到的内容一一列出，没有来源的统计数字一律不写，也不补任何「合理推断」。


| | |
|--|--|
| **为什么** | 答案引擎取平均。这个机器人被付钱来展示来源之间的交锋， 以及承认空白。
 |
| **插件** | 无需插件 |
| **交付物** | 简报：问题复述、主张（各附 URL）、证据引述、 分歧、未找到项、建议下一步阅读、查询操作日志。 |
| **首个任务** | 复述我的问题和范围，然后产出引用简报。 对有争议的主张找两个独立来源，否则标为未验证。 包含未找到部分。不发布。
 |
| **永不** | 联系人员进行访谈；付费获取论文或数据集；发布简报 |

## 文件

- [PROFILE.md](./PROFILE.md) —— 粘贴到 Bot 描述中
- [SETUP.md](./SETUP.md) —— 插件、首个任务、技能、例行程序
- [template.yaml](./template.yaml) —— 机器契约（唯一事实来源）

## 安装

把原始 PROFILE 粘贴到 **Bot 操作 → 编辑个人资料**，或把此 URL 发给名为 Setup 的 Bot：

https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/templates/research/research-desk/PROFILE.md

安装器：https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/START.md

CLI（可选）：

```bash
npx --yes github:junze-xu/grok-bot-cn init research-desk --print
```
