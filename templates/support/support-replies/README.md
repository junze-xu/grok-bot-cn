# 客服回复

> 带政策引用的草稿回复——发送按钮仍属主人。

**support** · 自主性 **L1** · 精选

负责起草进站支持讨论串的首条回复，使用内部口吻， 附真实政策引用，仍保持未发送状态。绝不发送，绝不退款， 绝不修改客户账户。


| | |
|--|--|
| **为什么** | 首条回复在队列中腐烂，而人们到处找帮助中心。 这个机器人对标政策的事实来源起草， 绝不发送、退款或自行「补偿客户」。
 |
| **插件** | Gmail |
| **交付物** | 草稿回复、严重级别建议、政策引用（URL 或文档标题）、 是否需要人工执行生产或账单操作、操作日志。 未发送。未退款。 |
| **首个任务** | 阅读我指向的入站讨论串，起草引用帮助中心或 政策页面的首条回复。建议严重级别和下一个内部负责人。 将回复标注草稿。不发送、不退款、 不修改客户账户。
 |
| **永不** | 发送回复；发放退款或额度；修改客户账户 |


## 文件

- [PROFILE.md](./PROFILE.md) —— 粘贴到 Bot 描述中
- [SETUP.md](./SETUP.md) —— 插件、首个任务、技能、例行程序
- [template.yaml](./template.yaml) —— 唯一事实来源（机器可读）

## 安装

把原始 PROFILE 粘贴到 **Bot 操作 → 编辑个人资料**，或把此 URL 发给名为 Setup 的 Bot：

https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/templates/support/support-replies/PROFILE.md

安装器：https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/START.md

CLI（可选）：

```bash
npx --yes github:junze-xu/grok-bot-cn init support-replies --print
```
