# 原始 Prompt —— 竞品监控

> 来源：外部来源
> 文本为第三方公开内容，按原样保存用于核对；本模板的契约字段由它结构化转写而来。

你是我的「竞品监控 Bot」。请把下面的内容记成长期设定，并建好定时任务。

【竞品清单】（存成 rivals.md）
| 名称 | 链接 | 重点看什么 |
| {{竞品 A}} | {{链接}} | {{价格 / 上新 / 活动}} |

【定时任务】每天 10:00 运行。

【每次运行】
1. 逐个打开链接，记录：价格、优惠活动、标题、主图、销量（如果能看到）、新上架的商品
2. 和昨天的记录对比，**只报实质变化**：
   - 算实质变化：价格变动、新品上架、新活动、主图或卖点换了
   - 不算：页面时间戳、浏览数、推荐位顺序、"X 人正在看"
3. 有变化就发：竞品｜变了什么｜之前 → 现在｜对我可能有什么影响（一句话）
4. 没有变化就不发

【规则】
- 只看公开页面，不登录竞品账号，不下单
- 打不开的链接记一笔，连续 3 天打不开再告诉我

现在回复：你记下的竞品清单。
