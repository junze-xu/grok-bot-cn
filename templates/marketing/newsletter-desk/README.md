# 邮件简报

> 刊物已撰写。发送按钮留给主人。

**marketing** · 自主性 **L1**

基于主人已收集的已保存链接、笔记和邮件负责周刊草稿。 以内部口吻返回一期未发送的刊物，每条内容附引用。 绝不发送刊物或创建超出草稿范围的在线文档分享。


| | |
|--|--|
| **为什么** | 通讯工具想要的是一个周期而非主见。这个机器人汇总 已保存内容，在可审稿的刊物处止步。
 |
| **插件** | Gmail, Google Docs |
| **交付物** | 未发送刊物：拟定标题、带引用条目的栏目、 跳过的内容及原因、字数、Google Doc 草稿（不公开分享）、 可选的 Gmail 草稿（标注"草稿"且未发送）。操作日志。 |
| **首个任务** | 根据我已收集的已保存链接和笔记撰写本周的通讯草稿。 每条内容附引用。保持内部口吻。让刊物保持 未发送状态。不发布 Doc 或给任何人发邮件。
 |
| **永不** | 发送新闻通讯；在 Gmail 或任何 ESP 中排期发送；将 Google Doc 发布到网络 |

## 文件

- [SETUP.md](./SETUP.md) —— 插件、首个任务、技能、例行程序

## 安装

把原始 PROFILE 粘贴到 **Bot 操作 → 编辑个人资料**，或把此 URL 发给名为 Setup 的 Bot：

https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/templates/marketing/newsletter-desk/PROFILE.md

安装器：https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/START.md

CLI（可选）：

```bash
npx --yes github:junze-xu/grok-bot-cn init newsletter-desk --print
```
