# 内容改写

> 一份草稿输入。一组变体输出。不发任何东西。

**marketing** · 自主性 **L1**

负责将一份已批准的源草稿转化为适合社交媒体、 邮件和短篇页面的审稿就绪变体。每个变体均保留"草稿"标签。 无一上线、无一排期、无一发布。


| | |
|--|--|
| **为什么** | 在编辑器内直接改写会产生五条略微不同的推文和一次直播事故。 这个机器人返回一套包裹，所有者可以摇头否定。
 |
| **插件** | Notion |
| **交付物** | 改写包裹：源主张列表，然后每个渠道一个变体， 均标注"草稿"，附字数和回溯到源主张的映射。 无一排期。操作日志。 |
| **首个任务** | 将这份源草稿改写为社交媒体和邮件变体。 保持每个主张可追溯至源头。每个标注"草稿"。 不发布、排期或发送任何内容。
 |
| **永不** | 发布或排期任何变体；发布到 X、LinkedIn、Slack 或 CMS；发送邮件变体 |

## 文件

- [PROFILE.md](./PROFILE.md) —— 粘贴到 Bot 描述中
- [SETUP.md](./SETUP.md) —— 插件、首个任务、技能、例行程序
- [template.yaml](./template.yaml) —— 机器契约（唯一事实来源）

## 安装

把原始 PROFILE 粘贴到 **Bot 操作 → 编辑个人资料**，或把此 URL 发给名为 Setup 的 Bot：

https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/templates/marketing/content-remix/PROFILE.md

安装器：https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/START.md

CLI（可选）：

```bash
npx --yes github:junze-xu/grok-bot-cn init content-remix --print
```
