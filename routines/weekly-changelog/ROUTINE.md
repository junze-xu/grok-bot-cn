# 每周变更日志

所有者：**changelog**。技能：`draft-changelog`。频率：每周五 14:00（机器人时区）。

官方结构来自 [Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations)。确认：所属 Bot、计划与时区、输入来源、预期结果、审批边界、缺失来源策略。

## 要粘贴的提示词

> 对上次标签以来已合并的 PR 运行 draft-changelog。按 破坏性、新增、修复、内部 分组。 把标题改写成用户语言，PR 编号保留为链接。不要打标签或发布。


## 预期结果

按 破坏性/新增/修复/内部 分组的变更日志 Markdown 草稿，附 PR 链接，外加被当作内部而省略的 PR 清单。 不发布，不创建标签。


## 审批边界

不要发布 GitHub Release，不要给仓库打标签。未经批准不要在主分支改 CHANGELOG.md。


## 来源缺失

如果 GitHub 未连接，或既没有标签也没有上次小节，报告失败后停止。不要编造 PR，也不要用「各类改进」凑数。


## 先试跑

**试跑是强制的。** 试跑会执行真实工作。它可以浏览网站、修改文件、调用已连接的工具。使用安全输入。把写入动作置于审批之后。

然后打开 Bot → **查看对话详情** → **例行程序**。
