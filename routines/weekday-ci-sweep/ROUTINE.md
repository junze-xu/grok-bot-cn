# 工作日 CI 巡检

所有者：**ci-sweeper**。技能：`sweep-ci`。频率：每周工作日 09:00（机器人时区）。

官方结构来自 [Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations)。确认：所属 Bot、计划与时区、输入来源、预期结果、审批边界、缺失来源策略。

## 要粘贴的提示词

> 对指定仓库运行 sweep-ci，扫描范围是昨天 09:00 以来。把新故障与 flake 分开，引用日志行，建议负责人， 列出挂起项。不要合并，不要为变绿反复重跑。


## 预期结果

扫描报告：新失败、flake、基础设施/超时、建议挂起的检查，附检查名和运行 URL。 不合并，不为变绿反复重跑。


## 审批边界

不要在 GitHub 上合并、推送或评论。不要取消工作流或更改分支保护。至多重跑一次，且仅在日志被截断时。


## 来源缺失

如果 GitHub 未连接，或某指定仓库打不开，针对该仓库报告失败后停止。不要编造 job，也不要把缺失的日志当作绿色。


## 先试跑

**试跑是强制的。** 试跑会执行真实工作。它可以浏览网站、修改文件、调用已连接的工具。使用安全输入。把写入动作置于审批之后。

然后打开 Bot → **查看对话详情** → **例行程序**。
