# Teams

2–4 Bots, one group, one kickoff. Installer never creates more than four.

Paste [START.md](https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/START.md) into a Bot named Setup and tap a team.

CLI (optional):

```bash
npx --yes github:junze-xu/grok-bot-cn teams
npx --yes github:junze-xu/grok-bot-cn init --team eng --out ./eng-bots
```
