# 插件（连接器）

官方：**设置 → 插件**。市场 vs 你的插件。已安装的连接器是**账号级**的，不是按 Bot 分的。优先使用连接器，而不是点击网站。输入 `@` 附加连接器；`/` 用于技能。

本目录按插件在简介中出现的名字命名（`GitHub`、`Gmail`、`Slack`、`X`、`LinkedIn`、`Notion`、`Google Calendar`、`Google Drive`、`Google Docs`）。实时市场集合会变。如果你的应用里缺某个名字，使用共享电脑上的浏览器，并在首个运行笔记中说明。

因为连接器是共享的：

- 不要把「只有这个 Bot 有 Gmail」当作控制手段
- 当整个名册都应失去某个服务时，退出登录它
- 在来源提供商处撤销，而不仅仅在 Grok Bot 中

团队安装器只列出一次插件的**并集**。
