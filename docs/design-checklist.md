# 设计清单

把它打印出来，放在新的 `template.yaml` 旁边。官方顺序来自[用例](https://docs.x.ai/grok-bot/use-cases)。

- [ ] 一个陌生人也能评分的任务
- [ ] 不同的工具／来源
- [ ] 不同的工作风格
- [ ] 不同的审批边界
- [ ] 描述承载常设规则；消息承载本任务
- [ ] 交付物可审查（事实／推断／已完成／等待中／问题）
- [ ] 首个任务在空对话中可运行，或询问唯一缺失的输入
- [ ] 无数据和数据过期策略
- [ ] 第一周是 L1
- [ ] 成功之后技能六字段就绪
- [ ] 例行程序仅在两次良好运行 + 试跑 + 缺失来源策略之后
- [ ] 群组交接每个阶段只有一个负责人
- [ ] 分享安全（无密钥、无内部 URL）
- [ ] `grokbot score` ≥ 80
