# 你想做什么？

这是一个**运营 Grok Bot 的模式库**。它不是「给我造 50 个智能体」的按钮。

| 我想… | 从这里开始 |
|------------|------------|
| 今晚就搭起第一个团队 | 把 [START.md](https://raw.githubusercontent.com/junze-xu/grok-bot-cn/main/START.md) 粘贴到名为 Setup 的 Bot 中 |
| 审查 PR 而不是橡皮图章 | `pr-reviewer` |
| 在不发送消息的前提下研究客户 | `sales-outbound` |
| 一份不是第二个收件箱的摘要 | `chief-of-staff` |
| 一份怀疑者也能审计的简报 | `research-desk` |
| 不泄露地分享一个 Bot | `sanitizer` |
| 设计一个能通过 CI 的 Bot | `roster` |
| 在发布／阻断决策前先有证据 | `evidence-packager` |
| 用一个超级 Bot 之外的方式分流工作 | `roster` |
| 给我写的契约打分 | `npx --yes github:junze-xu/grok-bot-cn score <id>` |

完整目录：粘贴 START.md，或 [Pages 目录](https://junze-xu.github.io/grok-bot-cn/)（复制 PROFILE）。机器 API：[agent.md](./agent.md)。
