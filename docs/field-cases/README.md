# 现场案例

在一个来自本目录的团队上真实跑一周，胜过再写二十个 YAML 文件。

## 模板

实际运行之后，把它复制到 `docs/field-cases/<id>.md`。

```md
# Eng 团队在 <repo> —— YYYY-MM-DD 那一周

- 团队：Eng（bug-reproduction、issue-drafter、pr-reviewer）
- 仓库：公开 URL 或「私有，已描述」
- 插件：GitHub
- 自主性：整周 L1

## 发生了什么
- 第 1 天：…
- 第 3 天：…
- 第 7 天：…

## 产出物（已脱敏）
链接或粘贴审查包／未发送的 issue／复现笔记。只用假名。

## 永不清单命中
Bot 拒绝了什么，以及那是否正确。

## 仍需手工打字
人类仍必须做的步骤。

## 我们会启用例行程序吗？
是 / 暂不 —— 以及为什么。
```
