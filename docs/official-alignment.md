# 与官方对齐

本目录**与 xAI 无隶属关系**。它依据截至 2026-08-29 的公开 Grok Bot 文档编写。

| 文档 | 我们采用的 |
|-----|----------------|
| [入门](https://docs.x.ai/grok-bot/get-started) | 合格套餐、桌面应用、首个任务形态（结果、来源、约束、交付物、审查点） |
| [Bot](https://docs.x.ai/grok-bot/bots) | 单一任务；描述 vs 消息；按范围复制；分享链接复制配置而非电脑；50 个 Bot + 群组上限 |
| [用例](https://docs.x.ai/grok-bot/use-cases) | 官方任务形态（外联、人才侦察、付费媒体、费用管理、产品绩效、Bug 复现、账户健康、参谋长）以及「把一个示例变成持久 Bot」的七步法 |
| [技能与例行程序](https://docs.x.ai/grok-bot/skills-routines-and-automations) | 六字段技能；例行程序确认；试跑是真实工作；不要宽泛监听器；50 个例行程序／20 条运行记录 |
| [电脑与应用](https://docs.x.ai/grok-bot/computer-and-apps) | 一台共享电脑；连接器即插件；`/workspace`；两步验证时接管 |
| [审批](https://docs.x.ai/grok-bot/approvals-security-and-privacy) | 常设边界；自动审查；本地电脑策略；分享不是安全边界 |
| [聊天](https://docs.x.ai/grok-bot/chat-and-collaboration) | 2–6 人群组；`@` 提及；可见交接；每阶段一个负责人 |
| [文件](https://docs.x.ai/grok-bot/files-and-results) | 可审查的成品；事实／推断／已完成／等待中／问题 |
| [设置](https://docs.x.ai/grok-bot/settings-and-notifications) | 例行程序的时区；插件市场 vs 你的插件 |

如果某个模板与这些冲突，以文档为准。开一个 issue。
